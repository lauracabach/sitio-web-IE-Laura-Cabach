La asignatura trabaja en la intersección entre el diseño y la programación, acercándose a lo que uno nombraría como arte generativo.

Se trabajan habilidades como el pensamiento computacional, lenguaje de código, saber trabajar elementos gráficos, interacción con el diseño, entre otros.

Para su desarrollo se trabajó con P5.js como la herramienta principal para crear los diseños. En ella se utiliza el lenguaje de código JavaScript, a través del cual se definen los elementos y comportamientos del diseño a crear.
